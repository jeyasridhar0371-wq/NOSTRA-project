
# Nostra Website Clone

A responsive **Nostra website clone** built using **HTML, CSS, and JavaScript**.
This project was created to improve my frontend development skills, with a major focus on learning and practicing **JavaScript**.

## 🚀 Features

* Responsive design
* Interactive user interface
* Multi-page website
* Product listing section
* Contact page
* Smooth navigation and styling

## 📄 Pages Included

1. **Home Page**

   * Landing section
   * Featured products
   * Navigation bar

2. **Products Page**

   * Product display layout
   * Product cards and styling
   * Responsive product section

3. **Contact Page**

   * Contact form UI
   * User-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 What I Learned

Through this project, I learned:

* DOM manipulation using JavaScript
* Event handling
* Responsive web design
* Page structuring with HTML
* Styling and layouts using CSS
* Creating interactive frontend components
